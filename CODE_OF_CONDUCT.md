# Code of Conduct

Commit CI Preflight is committed to a respectful, technically rigorous, and
harassment-free collaboration environment.

Contributors must:

- discuss ideas and evidence rather than attacking people;
- respect privacy, confidentiality, licensing, and security boundaries;
- avoid discriminatory, threatening, sexualized, or abusive conduct;
- accept maintainers' good-faith moderation decisions;
- report sensitive conduct concerns privately rather than escalating them in
  public issue threads.

Maintainers may edit, hide, reject, or remove contributions and participation
that violate these expectations. Repeated or severe violations may result in a
temporary or permanent ban from project spaces.

Until a dedicated private conduct channel is published, request private contact
through a minimal GitHub issue that contains no sensitive details.
